Agentic public-service proof

Helpful enough to act.

A narrow prototype for agentic assistance in public administration: help people discover services, prepare evidence, understand procedures and coordinate hand-offs — while keeping legal authority, user agency and an auditable action boundary explicit.

OPERATING CONTRACTAssist ≠ decide.

The agent can orient, prepare, explain and coordinate. Binding entitlement decisions remain outside the agent. Consequential external actions require explicit confirmation.

01 / thesis

Agentic AI should improve rights in practice, not just efficiency.

The interesting question is not “can an agent fill a form?” It is whether an agent can reduce navigation burden while preserving responsibility, transparency, data control and the difference between advice and legally binding administration.

Orientation

Translate a life event into possible service routes without claiming eligibility.

Application preparation

Collect reusable facts, identify missing evidence and prepare an application package.

Procedure

Make status, deadlines and next steps visible.

Communication

Explain authority requests in plain language while preserving the original message.

Orchestration

Coordinate cross-agency hand-offs without inventing jurisdiction.

Monitoring

Surface systemic bottlenecks in aggregate — not individual enforcement scores.

03 / guardrails as product behavior

Not a principles PDF. Executable invariants.

ALLOWED

Prepare before act

Draft, classify, explain, route and assemble evidence.

CONFIRM

Consequential side effects

External submission requires an explicit user confirmation event recorded in the receipt.

BLOCKED

Binding entitlement decision

The agent cannot promote itself into the legal decision-maker.

AUDITABLE

Every executed action has a receipt

Action ID, role, source, outcome, confirmation state and explanation are retained.

04 / what I would research next

The risky edge cases are the product.

Discovery agenda

Citizen research: Where do people currently mistake guidance for an official decision? When is confirmation useful versus burdensome?

Caseworker research: Which preparatory actions genuinely remove work, and which merely move ambiguity downstream?

Legal/domain workshop: Map every action to authority, reversibility, legal effect and required human responsibility.

Red-team: wrong service routing, stale data, contradictory evidence, inaccessible communication, cross-agency data overreach, accidental submission and overconfident language.

Metrics: successful service discovery, abandoned journeys, clarification loops, time saved, correction rate, inappropriate-action blocks and citizen comprehension of the system's authority.

05 / implementation proof

The boundary is testable.

The repository contains a deterministic action-policy module and tests that require six assistance roles, block binding decisions, require confirmation for submission, preserve provenance receipts and constrain monitoring to an aggregate purpose.

Targeted, not affiliated: This independent proof responds to Agora Digitale Transformation's public work on agentic AI for democratic, rule-of-law administration. It does not reproduce an Agora implementation and is not presented as an official system.

Engine · Tests · Agora project
