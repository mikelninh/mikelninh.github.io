# Product spec

## User
A recruiter, hiring manager, product manager, UX designer, or engineer reviewing a Tech Analyst application.

## Job to be done
Understand where a synthetic broker signup flow loses users, why the biggest recoverable loss occurs, and how that finding turns into an implementable improvement.

## Acceptance criteria
- 10,000 deterministic synthetic signups
- funnel from start to account opening
- root-cause breakdown
- device/provider segmentation
- one prioritized intervention
- one user story and four acceptance criteria
- transparent model assumption and limitations
- responsive static demo
- executable verification
