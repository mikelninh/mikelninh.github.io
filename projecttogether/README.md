## Test first, then scale

1. Recruit volunteer organisers from an existing community and define one outcome per project.
2. Make the first meaningful contribution achievable within 10 minutes.
3. Verify output with the organiser, not only self-reported clicks or points.
4. Compare completion rate and organiser effort against their baseline before scaling.
