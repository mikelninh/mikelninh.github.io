# Beyond CV → Semantic City → DKSR

The concurrently published original `beyond-cv/index.html` and its README, personal copy, gift, question cards and reflection builder are preserved. This is an additive integration, not a competing personal page.

## Paths

- `/beyond-cv/` keeps the original personal introduction, future vision and local reflection tool.
- `/beyond-cv/dksr/` is the German, proof-first independent work sample.
- The built personal page gains one compact work bridge before the recruiter invitation. The portfolio navigation gains a Beyond CV link only if one is not present.

`../link_portfolio.py` makes guarded build-time additions. Removing the exact bridge restores the original personal HTML byte-for-byte. Both the Pages build and the public exact-hash delivery check run the same compilation step. There are no automatic source commits. An unexpected/edited anchor fails closed.

## Claim boundaries

This page is an authored replay of the pinned Berlin record at COMMONS commit `82f8d810762146eeda0d52b6fe02b87d4441f7d1`. It neither runs a live WFS query nor ranks districts. The underlying recommendation template, approximate spatial joins, SHACL structure-only validation and unproven municipal portability are disclosed. No DKSR commission, affiliation or CIVORA integration is claimed. Reported beds are not free capacity and modelled 2022 climate is not current weather.

The original free prompt/reflection tool remains the only gift. No duplicate form, tracker, model API, key, payment or account is added. Contact is a mailto link; nothing is sent automatically.

## Checks

`python beyond-cv/dksr/check.py` runs preservation, navigation, actual browser evidence tabs, keyboard interaction, mobile overflow, original reflection builder, original prompt clipboard and no-JavaScript tests. CI stores actual screenshots/reports and the built review files as artifacts. `BEYOND_CV_BASE` optionally verifies the same checked-in case against a deployed base URL.

No local DOM smoke is represented as production correctness or independent validation of the city model. COMMONS PR #101 is not merged by this work.
