The future I want to contribute to

A future where public services are easier to access, health technology protects dignity, democratic tools empower citizens, and ethical choices become simpler through better systems and better design.

Great technology should make people freer, healthier, and more capable. My work focuses on AI systems that help humans understand, decide, and act. I'm betting the next decade is agentic — AI agents and durable loops doing real, reliable work — and I want to build it, daily, with tools like Claude Code and Codex.

AI agents I want to build

Citizen Agent: helps people understand letters, forms, benefits, deadlines, laws, and next steps.

Health Companion: helps patients track symptoms, questions, medication effects, doctor preparation, and emotional load.

Mission Ops Agent: helps NGOs, public-good teams, and health startups automate research, documentation, outreach, and knowledge workflows.

Workflow Builder: connects tools, APIs, data, and LLMs into useful automations people actually want to use.

The pattern underneath: durable agent loops — Loop · Skill · Orchestrator — that checkpoint every step, retry on failure, and keep running whether or not a human is watching. I've already built a working one (see Projects).

Less friction. More agency. Better systems for real human lives.

Proof — already shipped

Not ideas. Things I've actually built, that run today. Zeigen statt behaupten — show, don't claim.

INCA Claims-Loop ↗

A runnable agent loop: three agents, a receipt per decision, an eval harness. An application you can touch instead of read.

GitLaw + GitLaw Pro ↗

All 5,936 German federal laws, AI-explained and searchable via RAG over FAISS. Free citizen version live; Pro adds case-bound research and a multilingual client portal.

Recht-MCP Servers ↗

MCP servers that hand LLMs real, checked legal tools: contract review against §305 ff. BGB, parental allowance, housing benefit, EU flight rights. No API key needed.

SafeVoice ↗

Classifies a hate comment under German criminal law and generates a court-ready Strafanzeige in 30 seconds. Anonymous, DSGVO-clean. Free for victims.

Durable Job-Radar · in progress

An agent loop — Loop · Skill · Orchestrator on Inngest — that scores job-fit measurably and survives restarts via step-checkpointing. Working prototype, demo coming.

Berlin Taste Passport · in progress

B2B loyalty for live-shopping gastronomy — taste the city, reward coming back. In pilot prep.
