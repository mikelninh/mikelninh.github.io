One failure we actually found

In a small, real API comparison using 20 fictional travel-cancellation cases, GPT-4o mini missed two documents containing instructions that attempted to manipulate the AI. We added an independent check that catches those two known examples in an offline replay. This is useful development evidence, not a claim about performance on real claims.
