    This prototype is not connected to INCA or MARS. It replays invented agent traces and pre-written corrections. The browser runs genuine rule checks; it makes no new AI API calls, uses no insurer data, makes no payments, and does not claim production savings.

    02 · For engineers and operations

    From one correction to a regression gate.

    A small production-quality test pattern — not a production claims platform. Its actual business value would have to be measured on approved operational logs and human review time.

    01 / OBSERVE

    Capture the incident

    Keep the trace, source ID, policy revision, quotation, tool order and requested actions available for an operator to inspect.

    Output: replayable trace
    02 / CORRECT

    Human-guided resolution

    Identify the failed invariant, locate the applicable evidence, and stage a documented correction with no external side effects.

    Output: reviewed fixture
    03 / PREVENT

    Test before release

    Turn each failure mode into a deterministic regression test. Stop the simulated release if the same unsafe pattern returns.

    Output: Python and JS tests

    What this experiment does not establish: No access to MARS, no real agent integration, no production telemetry, no human reviewer minutes, no financial return and no automatically improved model. All twelve traces and corrections are developer-authored fiction. Six structural checks cover trace/source consistency, safe tool order, authorized actions and a bounded handoff; they do not determine policy coverage, liability or payment. At INCA, I would begin by learning which failure modes already have controls and which really recur.
