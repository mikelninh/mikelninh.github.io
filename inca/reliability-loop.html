What I actually built

One feedback loop. Two distinct improvements.

01 / RUNMake the model's failures visible.

Send fictional documents to a real model. Record structured output, route, evidence and API usage.

02 / IMPROVEChange one thing at a time.

First revise evidence-extraction instructions. Then fix a separate deterministic coverage-review priority bug.

03 / DECIDEEvaluate on different cases.

Compare unsafe continuations, unnecessary reviews, latency and estimated cost. Block unsafe releases.

What changed—and what didn't

**Experiment A:** baseline and revised prompts plus evidence guard evaluated on ten held-out fictional examples. **Experiment B:** the same recorded model outputs were routed through two deterministic policies on 20 different stress examples. No model was trained, and B made only 20 (not 40) API requests.

The holdout and stress cases share developer-authored templates, so neither is independent blinded validation.
