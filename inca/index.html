03
How I test a new model before it reaches a live workflow.
“Claude feels better” is not a release criterion. A new model or prompt earns promotion only when it improves the frozen cases without introducing new failure modes.

  

    
01Freeze casesSame inputs and expected next routes.

    
02Run bothOld and candidate prompt/model.

    
03MeasureRouting, schema, grounding, errors, latency.

    
04Inspect failuresWhat changed — and why?

    
05Promote or rejectNo vibes. No silent regressions.
