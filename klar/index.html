    Warum das fundamental ist

    Information ist nicht das Ziel. Handlungsfähigkeit ist das Ziel. OpenAction ist ein offenes Format für: Input → Bedeutung → Beleg → nächste Aktion → menschliche Freigabe → Ergebnis.

    Klar ist nur die erste Oberfläche. Dieselbe Schicht kann später Bürgerleistungen, Arbeit, Verträge, Gesundheit, Pflege und Verwaltung verbinden — ohne dass eine Firma dein Leben besitzen muss.
