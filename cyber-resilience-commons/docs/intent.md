# Intent

Cyber Resilience Commons makes cyber resilience understandable and actionable for organizations that cannot afford a large security team.

## User
Public administrators, hospital/school/NGO leaders, small-business owners, IT/security staff, policy makers and citizens.

## Job
Turn an abstract incident into: assets at risk → synthetic attack path → blast radius → stopping boundary → next fix → recovery drill.

## Success
A non-specialist can explain where an incident stops, what to improve next and why a synthetic result is not the same as real security assurance.
