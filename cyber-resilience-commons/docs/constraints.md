# Constraints

- Public-interest first: understandable without security jargon.
- Synthetic by design: no real Berlin or third-party infrastructure modeled.
- No network probing, credential use, exploit steps or arbitrary target input.
- No single security score that implies certainty.
- Every outcome must remain explicitly a planning-model result.
- Real assurance is only valid in an owned/authorized environment.
- Accessibility, mobile usability and printability are release requirements.
