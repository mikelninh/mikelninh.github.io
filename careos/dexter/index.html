01 · Product thesis

The LLM should write the draft.
The system should own the guarantee.

Care documentation is a perfect LLM workflow — and a terrible place to hide uncertainty. The safest useful pattern is not “better prompting”. It is a product contract around the model.

Failure modeExpected behaviourFixture result
Missing evidenceReject claim; ask for clarificationPASS · blocked
Malformed model JSONRepair once → deterministic fallbackPASS · fallback
Medication ambiguityNever infer dose or causalityPASS · escalated
Write-back without approvalPolicy layer denies actionPASS · denied

Deterministic reference checks, not claims about production clinical performance. The point is to make failure behaviour testable before swapping in any LLM provider.

04 · System shape

Provider-agnostic by design.
Clinical authority stays outside the model.

Commercial or self-hosted models can sit behind the same typed contract. The model proposes; deterministic services validate evidence, permissions and workflow state.
