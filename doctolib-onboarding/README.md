# AI Phone Onboarding Lab

Independent, synthetic role-fit work sample for technical onboarding / AI implementation.

The page demonstrates:
- technical preflight,
- API/network/VPN readiness,
- explicit data mapping,
- migration data-quality validation,
- go-live gating,
- documentation and handoff.

It is intentionally company-neutral and does **not** contain Doctolib/customer/patient data, copied product UI or production integration claims.

Core proof behind the demo: [CareOS](https://github.com/mikelninh/care-os).
