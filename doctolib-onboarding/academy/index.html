THE CAPSTONE

2-hour implementation case.

A synthetic multi-location practice. Incomplete technical information. One migration warning. A go-live deadline. You get the brief, investigate, decide, and present.

Start interview mode →
0–20 MINClarify assumptions, map current state, define success and blast radius.
20–60 MINInvestigate system / data evidence and prioritise the highest-information tests.
60–90 MINBuild implementation plan, test matrix, risks, owners, rollback and monitoring.
90–120 MINCreate a 6-slide recommendation and prepare for hiring-manager challenge questions.
