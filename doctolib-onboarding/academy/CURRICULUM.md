# Technical Onboarding Academy

## Objective
Prepare for a technical onboarding / implementation role by combining **concept learning**, **scenario practice**, **artifact creation**, and **presentation practice**.

## Learning loop
**Learn → Play → Produce → Present**

Every completed simulator run now automatically creates a **case dossier** containing the evidence gathered, insights, decision, verification, score breakdown, timeline, strength, next practice focus, and user reflection. Runs are saved locally in the browser and surfaced in the Academy progress view.

## Modules

### 1. Discovery & scoping
Learn: goals, patient journey, dependencies, stakeholders, owners, success criteria.  
Practice: New Clinic Go-Live.  
Artifact: implementation brief + current/target system map.

### 2. Integrations & infrastructure
Learn: API/auth, call routing, network/VPN, local configuration, fallback.  
Practice: Broken Calls.  
Artifact: integration preflight + troubleshooting decision tree.

### 3. Data migration & quality
Learn: field mapping, identifiers, duplicates, required fields, samples, exception handling.  
Practice: Dirty Migration.  
Artifact: migration QA report + Excel/SQL validation checklist.

### 4. Testing & go-live
Learn: critical-path acceptance testing, edge cases, rollback, monitoring, go/no-go.  
Practice: Go-Live Tomorrow.  
Artifact: test matrix + go-live / rollback plan.

### 5. Incident response
Learn: blast radius, containment, evidence hierarchy, recovery, root-cause analysis.  
Practice: Post-Launch Incident.  
Artifact: RCA + stakeholder update.

### 6. Documentation, training & automation
Learn: SOPs, training handoff, recurring-task automation, feedback loops.  
Practice: interview remix.  
Artifact: SOP + training one-pager + automation proposal.

## Capstone
2-hour synthetic implementation case.

- 0–20 min: scope, assumptions, success, affected journeys
- 20–60 min: technical/data investigation
- 60–90 min: implementation plan, tests, risks, rollback, monitoring
- 90–120 min: six-slide presentation + challenge questions

## Evidence pack
1. Implementation brief
2. Integration preflight
3. Migration QA
4. Test + go-live plan
5. Incident RCA
6. SOP + training guide
7. Automation note
8. Capstone presentation
9. Generated case dossier

The goal is not to look like you already worked at the target company. The goal is to show transferable judgement, technical fluency, structured implementation thinking, and the ability to communicate clearly.
