## About — recommended

I build reliable AI systems that turn messy real-world workflows into tested, observable software.

My focus is not simply getting an agent to produce an answer. I care about the system around it: what the agent is allowed to do, what evidence it needs, what happens when evidence is missing, how we evaluate failures, and where human judgement must remain in control.

My working loop is:

**Spec → Build → Evaluate → Verify → Ship → Monitor**

Coding agents do much of the implementation in my projects. I design the problem, architecture, specifications, autonomy boundaries, evals and evidence that make the result trustworthy.

Recent proof of work includes:

- **TrustReady** — an evidence-first control layer for sensitive AI workflows with deterministic policy boundaries and explicit human authority.
- **SafeTrace Entity Resolution** — a `merge / separate / review` resolver evaluated on a frozen 40-case developer-authored holdout; 34 automatic decisions, 6 routed to review, and zero false automatic merges/separations on that set.
- **DRV SignalLab** — deterministic monitoring over 50,000 synthetic administrative cases with data-quality checks, drift detection, confidence intervals, effect sizes and human-review boundaries.
- **Digital Worker Factory** — bounded AI workers with capability gates, required evidence, fail-closed behaviour and earned autonomy; a published 100-case synthetic release run completed without runtime errors, unsafe executions or false execution claims.

Before AI engineering, I built and operated an e-commerce business, worked in product/business development, and ran high-tempo service operations. That background makes me naturally start with the real bottleneck rather than the model.

I’m looking for an early-career role in **AI Engineering, Agentic Systems, AI Operations, Applied AI or AI-enabled intelligence/automation** where careful system design and hands-on building matter.
