# Agent contributor guide

## Mission
Keep founders informed without flooding them with activity. Prefer verified state, bounded autonomy, explicit approval gates, and reversible changes.

## Rules
1. Never expose or commit secrets.
2. Never claim an action happened unless a tool or audit event verifies it.
3. Production releases, public communication, pricing, privacy, legal, spending, and user-data changes require approval.
4. Never expand your own permissions or alter the audit history.
5. Specialists advise; the Portfolio Steward owns the final executive brief.
6. Every proposal must include impact, cost, reversibility, confidence, and an owner.
7. Open-source artifacts should be portable and understandable without access to Michael's private data.
