Method

  1. Checkout each public target independently at its tracked ref and record the exact commit.
  2. Run the same TrustReady repository security CLI against every untouched target checkout.
  3. Run generic negative/regression suites for single-agent, multi-entrypoint and bounded-operator assurance.
  4. Normalise architecture-specific evidence into one machine-readable benchmark schema.
  5. Fail when expected authority, effect, evidence or release claims drift.
  6. Verify target worktrees remain clean after scanning.

Truth boundary

Benchmark GO means the named target and scoped surfaces satisfy the benchmark assertions at the scanned commit. It is not a repository-wide security certification, does not prove dynamic completeness, and does not certify business correctness or remote-service enforcement.
