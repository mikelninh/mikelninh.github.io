Die KI liefert Hinweise. Menschen überprüfen unklare oder kritische Aussagen, bevor etwas weitergeht.

Wie funktioniert die KI? Architektur, Evaluation und ehrliche Grenzen

Der Browser ruft ausschliesslich synthetische Ticket-IDs auf der Serverroute /api/classify auf. Nur der Server besitzt OPENAI_API_KEY und sendet den vorgegebenen Nachrichtentext an die OpenAI Responses API. Structured Outputs erzwingen ein JSON-Schema; der Server prüft Belegzitate gegen den Originaltext, markiert Mehrfachanliegen und protokolliert Modellkennung, Dauer sowie Tokenverbrauch. Das LLM führt keine Versand-, Retoure- oder Erstattungsaktionen aus.

Die lokal ausgeführte Regelbaseline ist bewusst simpel. Ihre Fehler sind ein Vergleichspunkt, kein gemessener Produktionsstandard. Ein echter Qualitätsnachweis benötigt ein unabhängiges, menschlich annotiertes Holdout, mindestens Precision/Recall/F1 je Klasse, gemessene Sicherheitsfehler, Kosten und Latenz sowie eine Schwelle für menschliche Kontrolle. Die 24 gezeigten Fälle sind demonstrativ – nicht ein unabhängiger Test eines live eingesetzten Modells.

Für öffentliche, kostenpflichtige API-Nutzung muss vor breiter Freigabe zusätzlich ein verteiltes Rate Limit und Budgetlimit aktiviert werden. Keine Kundendaten, keine Shop-Konten, keine realen Produktdefekte. Dies ist ein unabhängiges Bewerbungsprojekt – keine offizielle SNOCKS-Software.
