Qualification

This is deliberately not for every AI product.

The pilot is strongest when the model sits upstream of a real-world action whose authority can be observed and enforced.

Good fit

  • Agent sends emails, messages or calls.
  • Agent creates, changes or deletes records.
  • Agent calls external APIs or tools.
  • Agent executes code or commands.
  • Agent crosses tenant, customer or case boundaries.
  • Agent operates in finance, insurance, legal, health or compliance workflows.

Not a fit

  • Text-only copilot with no consequential effect.
  • No owned / explicitly authorized sandbox or fixture.
  • Request depends on attacking third-party systems.
  • You need a formal penetration test or certification badge.
  • You want a promise that unknown vulnerabilities do not exist.
Truth boundary: the pilot produces scoped causal engineering evidence for the named paths tested. It does not certify the whole product, prove prompt injection is solved, or replace an independent penetration test for high-consequence production systems.
