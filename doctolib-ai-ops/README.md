# AI Operations Lab

Independent, synthetic role-fit work sample for an AI Operations / agent workflow role.

The page demonstrates:
- workflow redesign before automation,
- explicit context and freshness gates,
- bounded agent steps,
- deterministic eval checks,
- human release for consequential actions,
- impact measurement via time, quality, usage and cost.

It is intentionally company-neutral and does **not** contain Doctolib/customer data, copied product UI, production metrics or internal architecture claims.

Core proof behind the demo: [Digital Worker Factory](https://github.com/mikelninh/digital-worker-factory).
