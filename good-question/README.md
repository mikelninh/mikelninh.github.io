# GOOD QUESTION · Magazine, Issue 01

Trilingual vegan ethics/nutrition/environment magazine: DE / EN / VI.

This site is a static five-file build (HTML, CSS, JS) with no backend and no affiliate tracking.

## Evidence rules

- The original guidance/primary study is linked when checked. Details, cautions and review date appear in the open argument card.
- Source presence is not scientific validation. Non-checked arguments are marked **full source review pending**.
- These are **editorial source checks**, not independent clinical peer review and not formal GRADE certainty ratings.
- Health tools show sample meals, not a clinically validated nutrient calculation or personalised dietetic advice.
- All commercial relationships/affiliate links must be disclosed before adding them. No live affiliate links in this release.
- Open [evidence-register.json](./evidence-register.json) for a machine-readable audit record.

## Run locally

`python3 -m http.server 8080` then visit `http://localhost:8080/good-question/` from the repository root.
