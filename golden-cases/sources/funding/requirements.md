# Synthetic review requirement — Golden Case

This is the exact synthetic requirement used by the portfolio demo.

A reimbursement case is complete only when the submitted file contains:

1. Application
2. Final invoice
3. Payment proof
4. Signed acceptance protocol
5. Site photo evidence

The amounts stated in the application, invoice and payment proof must be consistent or explicitly explained before approval.

> Portfolio note: this requirement is synthetic. It demonstrates the source-linked review workflow; it is not presented as an actual legal or funding rule.
