## How this repository is organised

This repository hosts the public portfolio and selected application work samples. The homepage stays intentionally simple; technical details live in the linked project repositories.

Tailored application pages are kept separate from the main navigation so one portfolio can support different roles without turning the homepage into a wall of information.

## Principle

**Explain the problem simply. Show proof. Let engineers inspect the machinery.**

The portfolio is the human-readable layer. GitHub contains the implementation, tests, architecture and technical trade-offs.
