ENGINEERING, NOT MAGIC — 03 / 03

Useful by design.
Limited by evidence.

Good systems make uncertainty easy to find instead of hiding it beneath polished prose.

01
Real document reading

PDF.js extracts text from each page in your browser. Observations link to actual document names, page numbers and excerpts.

02
Inspect the rule, not a mysterious score

The prototype uses deterministic pattern matching. It does not validate financial statements, understand every deck, or call an LLM.

03
Missing stays missing

Differing numerical claims are flagged for review, not silently averaged or treated as confirmed dishonesty.

04
Earn automation with evidence

A real pilot should measure reviewer time including corrections, unsupported claims, overlooked facts and question usefulness.
