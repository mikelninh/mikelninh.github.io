3-Minuten Demo

Geführter Ablauf, kein Labyrinth.

Ein CTO soll nicht suchen müssen. Diese vier Schritte zeigen die Idee kompakt.

Warum relevant

Die interessante Frage ist nicht: “Kann eine KI antworten?”

Die interessante Frage ist: Kann sie kontrolliert, nachvollziehbar und nützlich in echte Verwaltungsprozesse eingebettet werden?

Für Bürger

Sie bekommen eine verständliche Antwort, eine Checkliste und Hilfe beim nächsten Schritt.

Für Fachbereiche

Sie bekommen strukturierte Übergaben statt chaotischer Freitext-Anliegen.

Für Admins

Sie können Wissen pflegen, statt auf Code-Deployments zu warten.

Für CTOs

Daten, Tools, Modelle und UI sind getrennt. Das macht das System testbar und austauschbar.

Architektur

Ein kleiner Stack, der größer werden kann.

01

Source Registry

Quellen mit URL, Amt, Status, Review, Aktualität und Vertrauenslevel.

02

Importer

URL/Text wird extrahiert, in Chunks vorgeschlagen und nie blind veröffentlicht.

03

Retrieval

Fragen werden gegen freigegebene Chunks gesucht. Confidence ist Trefferstärke, kein Wahrheitswert.

04

Serviceflow

Antwort, Routing, Termin, Ticket, Rückruf oder Handoff werden vorbereitet.

05

Receipt

Jeder Vorgang wird menschenlesbar und maschinenlesbar nachvollziehbar.

06

MCP Tools

Agents können später dieselben Tools nutzen: import_source, search_sources, classify_statement, create_receipt.

Truth / Text Analyzer

Worüber streiten wir eigentlich?

Für Bürgerkommunikation, interne Diskussionen und Agenten ist es wertvoll, Aussagearten zu trennen: Fakt, Wert, Gefühl, Glaube, Prognose.

Was ich als Nächstes bauen würde

Vom Prototyp zum Tool, das andere Agents nutzen können.

1. Persistente Source Registry

Postgres/Supabase statt LocalStorage. Quellen, Chunks, Reviews, Owner, Versionshistorie.

2. Real MCP Server

Ein kleiner Server mit Tools für Import, Suche, Klassifikation, Action Payloads und Receipts.

3. Eval Harness

Jeder neue Chunk muss Standardfragen bestehen. Regressionen werden sichtbar.

4. Integrationen

Kalender, Ticketing, Rückrufsystem und Analytics als austauschbare Adapter.
