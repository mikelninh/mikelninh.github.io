All three models returned the expected next route for these five cases.

## Important discrepancies

The scorer reports 100% route match, true-flag recall, and fact accuracy **on only these five fixtures**. It currently does **not** score false-positive extraction flags. Comparing the returned booleans with the existing developer-authored labels showed:

- `gpt-4o-mini`: 0 false-positive flags
- `gpt-6-luna`: 1 extra `ambiguous` flag (DOC-EVAL-047)
- `gpt-6.1-sol`: 3 extra `ambiguous` flags (DOC-EVAL-007, 047, 077)

These differences did not change the next route, but they should be evaluated separately in the next version of the scorecard. `gpt-4o-mini` is an older/deprecated model and is not an automatic production recommendation.

## Interpretation and limits

This is the **first completed real API run**, not a dry run. It verifies a complete synthetic text → LLM extraction → deterministic routing → measured report path for these five examples. It does not show full-PDF parsing, claims expertise, robustness on unseen realistic claims, calibration, suitability for automatic payments, or statistically significant differences between model families.

**No model winner can be claimed.** Next benchmark should be a larger independently designed held-out dataset, plus false-positive precision, source-level faithfulness, and price-versus-quality comparisons. Do not equate these 5/5 results with reliability on live insurance claims.
