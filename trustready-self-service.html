What happens after preflight

Install the gate where the effects actually live.

The generated workflow runs only a fixed target-owned Security Delta recipe. TrustReady validates the emitted evidence and fails closed if an impact escape or benign regression remains.

  • Supported recipes: npm, Node, Python Security Delta harnesses.
  • No arbitrary command from repository config is executed.
  • Source-only findings never become runtime TECHNICAL_GO.

Evidence standard

GO has to be earned.

A valid target proof requires named attacks to reach impact in the controlled baseline, zero post-boundary impact escapes, full benign retention, and full containment of any declared holdouts.

Not claimed: penetration-test coverage, certification, production-wide security, or absence of unknown vulnerabilities.
